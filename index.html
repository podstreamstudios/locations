§ 1 · The Comparative Architecture

Three circles. Seven lenses.

In 2003, Kline, Dyer-Witheford and de Peuter published Digital Play — a three-circuit model of interactivity (Technology / Marketing / Culture) with an outer circulation loop mapping production, consumption, and commodity relationships. Flynn's 2006 MASc thesis at SFU SIAT worked directly from this structure. The three-circle pattern was present and operational from that point.

In 2014–15, the Queensland University of Technology Design Lab's Urban Informatics framework — People / Place / Technology — surfaced as an independent convergence with Flynn's existing three-layer pattern. QUT is validation, not source. The rotation shown below — Technology at top, Place at bottom-left, People at bottom-right — is Flynn's adaptation, mapping the QUT circles onto the Benjamin/Flynn value registers (exhibition / exchange / cult) and RPV (Resources / Values / Processes) simultaneously. The rotation is the intellectual move, not the circles themselves.

§ 2 · The Field Site Network

Seven nodes. Seven angles.

Each node must satisfy Ashby's Law of Requisite Variety: it must add genuine variety that no other node carries — different scale, different cultural context, different register emphasis. Geographic spread alone is not enough. Miller's Law governs the target: 7±2 nodes, cognitively manageable and methodologically sufficient.

The switching between nodes is not geographic browsing. It is Cole's coordinated lenses methodology made navigable. Each node illuminates something the others cannot see from their position.

§ 5 · System Architecture

A Viable System. Not a list of places.

The locations network maps onto Stafford Beer's Viable System Model. Each node is not an independent site — it is a functional component in a self-regulating system. The network routes demand, coordinates variety, governs membership, scans for new field sites, and maintains policy coherence through a single identity register: the George Crooney persona.

VSM System Function locations.crooney.ca Equivalent
System 1 · Operations Each operational unit doing its own work in its own environment Individual location nodes operating in their own markets — VanIsle in BC spirits, Vegas in proptech/LBE, ANZA in Pacific Rim
System 2 · Coordination Shared schema preventing oscillation between units |F|D|S|L| schema + P·S·L framework applied consistently across all nodes — the language that makes nodes legible to each other
System 3 · Control Governance determining what's "in" the viable system VICSS GI / VanIsle appellation — the instrument that defines membership; the Licence layer that authorizes value transfer
System 4 · Intelligence Scanning the environment for variety gaps and future states lab.crooney.ca / phd.crooney.ca — the research function that identifies new nodes and tests theoretical claims in new contexts
System 5 · Policy Values and identity holding the whole system in coherence crooney.ca / George Crooney persona — the consistent register across all nodes; the identity that travels from Campbell River to Las Vegas to Byron Bay

The network has two node types. Origin nodes — Vegas, Euro, Japan, UK — generate demand and route it toward VanIsle via register-specific mechanisms. Destination nodes — VanIsle, Vancouver — receive and retain. ANZA is the only dual-function node: it routes ANZ buyers toward VanIsle and routes Vancouver production outward to Australia simultaneously.
